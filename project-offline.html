Offline School Management System

Project Overview & Objectives

Innovative single-file browser-based School Management System engineered to solve severe load-shedding and internet connectivity outages in Zambian schools. Operates entirely client-side with persistent IndexedDB storage and zero monthly server expenses.

Key Engineering Accomplishments:

  • Guaranteed 100% uptime regardless of internet outages or national power load-shedding.
  • Automated timetabling scheduler resolving subject conflicts across 32 classes and 67 teachers in seconds.
  • Instant search, filtering, and grade computations for over 1,200 students with sub-millisecond response times.
  • Zero cloud server fees, zero subscription costs, and completely portable across any USB drive or device.

Technology Stack:

Vanilla JavaScript (ES6+) IndexedDB API HTML5 CSS3 Local Storage CSV Engine

System Architecture

Zero-server single-file application. Core business logic, constraint-satisfaction timetabling algorithms, and data persistence run directly in browser memory and IndexedDB, with automated JSON/CSV local backup exports.

// IndexedDB Persistent Storage Architecture
class SchoolDatabase {
  constructor() {
    this.dbName = 'LindaSchoolDB';
    this.dbVersion = 2;
    this.db = null;
  }

  async init() {
    return new Promise((resolve, reject) => {
      const request = indexedDB.open(this.dbName, this.dbVersion);
      request.onupgradeneeded = (e) => {
        const db = e.target.result;
        if (!db.objectStoreNames.contains('students')) {
          const store = db.createObjectStore('students', { keyPath: 'id', autoIncrement: true });
          store.createIndex('examNo', 'examNo', { unique: true });
          store.createIndex('class', 'gradeClass', { unique: false });
        }
      };
      request.onsuccess = (e) => { this.db = e.target.result; resolve(this.db); };
      request.onerror = (e) => reject(e.target.error);
    });
  }

  async saveStudent(student) {
    const tx = this.db.transaction('students', 'readwrite');
    tx.objectStore('students').put(student);
    return tx.complete;
  }
}
