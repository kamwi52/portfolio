DevCoach Android App

Project Overview & Objectives

Interactive software engineering learning companion designed to mentor aspiring developers through curated coding roadmaps, interactive quizzes, automated push study reminders, and an integrated AI browser assistant.

Key Engineering Accomplishments:

  • Curated curriculum roadmaps across React, Next.js, Node.js, Android (Kotlin), and Database Design.
  • Automated daily study schedule reminders using Android WorkManager background tasks.
  • In-app AI browser assistant allowing students to query documentation and receive contextual code explanations.
  • Interactive self-assessment quizzes with local progress tracking and mastery badges.

Technology Stack:

Kotlin Android SDK MVVM Pattern WorkManager Room Database WebView Integration

System Architecture

Kotlin Clean MVVM architecture with Android WorkManager for background notifications, Android WebView security hardening, and Room DB for bookmarking tutorials and offline quiz sessions.

// Android WorkManager Daily Study Notification Worker
class DailyStudyReminderWorker(
    ctx: Context,
    params: WorkerParameters
) : CoroutineWorker(ctx, params) {

    override suspend fun doWork(): Result {
        val topic = getDailyCurriculumTopic()
        showNotification("Time to Code! 🚀", "Today's Focus: $topic. Tap to start your 15-minute challenge.")
        return Result.success()
    }

    private fun showNotification(title: String, body: String) {
        val builder = NotificationCompat.Builder(applicationContext, CHANNEL_ID)
            .setSmallIcon(R.drawable.ic_code_study)
            .setContentTitle(title)
            .setContentText(body)
            .setPriority(NotificationCompat.PRIORITY_DEFAULT)
            .setAutoCancel(true)
            
        NotificationManagerCompat.from(applicationContext).notify(101, builder.build())
    }
}
