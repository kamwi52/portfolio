ZedIT Class eLearning Platform

Project Overview & Objectives

Interactive eLearning platform developed to support Zambian Computer Studies curricula for Grade 9 and Grade 12 students with practice test questions and curriculum resources.

Key Engineering Accomplishments:

  • Grade 9 and Grade 12 Computer Studies examination preparation dashboards.
  • Automated instant quiz scoring and answer explanations for past exam papers.
  • Modular CSV question bank architecture allowing teachers to add new quizzes without database migrations.
  • Intuitive user interface optimized for entry-level computer laboratory monitors.

Technology Stack:

PHP JavaScript HTML5 / CSS3 CSV Data Store Responsive Design
