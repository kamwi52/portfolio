Linda Secondary Results Portal

Project Overview & Objectives

Institutional academic management and report card distribution platform serving Linda Secondary School. Enables teachers to compute term grades, generate print-ready dynamic PDF report cards, and allows students to access results securely online.

Key Engineering Accomplishments:

  • Engineered automated PDF generation engine rendering individualized term report cards with institutional seal and grade analytics.
  • Streamlined end-of-term grading workflow, reducing administrative report production time from weeks to seconds.
  • Integrated Google OAuth2 authentication for role-separated teacher and student access.
  • Automated batch export and cloud archiving to Google Drive.

Technology Stack:

Next.js 14 TypeScript jsPDF Google OAuth2 Tailwind CSS Google Drive API

System Architecture

Next.js 14 App Router, TypeScript, jsPDF dynamic document generation engine, Google OAuth2 login authentication, and Google Drive cloud storage backups.

// Dynamic Report Card PDF Generation with jsPDF
import jsPDF from 'jspdf';
import 'jspdf-autotable';

export function generateReportCard(student, grades, termInfo) {
  const doc = new jsPDF();
  
  // Header & School Crest
  doc.setFont('helvetica', 'bold');
  doc.setFontSize(18);
  doc.text('LINDA SECONDARY SCHOOL', 105, 20, { align: 'center' });
  doc.setFontSize(12);
  doc.text(`OFFICIAL ACADEMIC REPORT — ${termInfo.term}, ${termInfo.year}`, 105, 28, { align: 'center' });
  
  // Student Metadata
  doc.setFontSize(10);
  doc.text(`Student Name: ${student.name}`, 14, 40);
  doc.text(`Exam No: ${student.examNo}`, 14, 46);
  doc.text(`Class: ${student.gradeClass}`, 140, 40);
  
  // Grade Table
  const tableData = grades.map(g => [g.subject, g.score, g.grade, g.remarks, g.teacher]);
  doc.autoTable({
    startY: 52,
    head: [['Subject', 'Score (%)', 'Grade', 'Teacher Remarks', 'Instructor']],
    body: tableData,
    theme: 'striped',
    headStyles: { fillColor: [15, 23, 42] }
  });
  
  doc.save(`ReportCard_${student.examNo}.pdf`);
}
