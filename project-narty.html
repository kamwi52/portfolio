Narty Rock School Portal

Project Overview & Objectives

Complete modern institutional school portal for Narty Rock School. Features role-based access control, homework assignment boards, school announcement feeds, and automated grade report card generation in a custom branded interface.

Key Engineering Accomplishments:

  • Role-separated dashboard views for Administrators, Teachers, and Parents/Students.
  • Automated academic report card publishing with instant student portal access.

System Architecture

Next.js 14 App Router, Tailwind CSS, multi-tier RBAC security layer (SuperAdmin, Teacher, Parent/Student), and automated cloud media storage integration.

// Next.js Middleware Role-Based Access Control
import { NextResponse } from 'next/server';
import type { NextRequest } from 'next/server';

export function middleware(request: NextRequest) {
  const token = request.cookies.get('session_token')?.value;
  const userRole = request.cookies.get('user_role')?.value;
  const path = request.nextUrl.pathname;

  if (path.startsWith('/admin') && userRole !== 'SUPER_ADMIN') {
    return NextResponse.redirect(new URL('/unauthorized', request.url));
  }
  
  if (path.startsWith('/teacher') && !['SUPER_ADMIN', 'TEACHER'].includes(userRole || '')) {
    return NextResponse.redirect(new URL('/unauthorized', request.url));
  }

  return NextResponse.next();
}
