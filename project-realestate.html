Livingstone Real Estate Platform

Kotlin · MVVM · Clean Architecture · Supabase · Drive API

Summary: Production-ready Android rental app designed for Livingstone landlords and tenants. Built with a focus on maintainability and offline resiliency. Key highlights:

  • Clean Architecture with separate Domain, Data, and Presentation layers
  • MVVM pattern using StateFlow for reactive UI and predictable state management
  • Supabase backend for auth and data storage; Google Drive proxy for cost-free media hosting
  • Optimised image upload and caching for low-bandwidth environments
  • Role-based flows for landlords, tenants, and property managers
