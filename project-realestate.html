Livingstone Real Estate Platform

Project Overview & Objectives

Production-ready native Android property discovery and rental management platform tailored for landlords, property agents, and tenants in Livingstone, Zambia. Engineered following strict Clean Architecture principles with reactive StateFlow state machines.

Key Engineering Accomplishments:

  • Engineered offline-ready caching using Android Room Database to allow tenants to browse saved listings without data.
  • Built a cost-free media storage engine using a custom Google Drive REST API proxy, eliminating expensive cloud storage fees.
  • Created reactive search filters with instant multi-criteria sorting (price, bedrooms, location coordinates, amenities).
  • Integrated direct landlord-to-tenant communication with automated WhatsApp and phone routing.

Technology Stack:

Kotlin Android SDK Clean Architecture MVVM Pattern StateFlow / Coroutines Supabase (PostgreSQL) Google Drive API Proxy ViewBinding

System Architecture

Strict separation of concerns across 3 modular layers: Presentation Layer (Kotlin Activities/Fragments, ViewBinding, StateFlow), Domain Layer (Use Cases, Business Rules, Repository Interfaces), and Data Layer (Supabase PostgreSQL Client, Room Database Offline Cache, Google Drive Media Proxy).

// Kotlin MVVM Repository & Clean Architecture Flow
class PropertyRepositoryImpl(
    private val supabaseApi: SupabaseApiService,
    private val localDao: PropertyDao,
    private val driveProxy: DriveMediaProxy
) : PropertyRepository {

    override fun getPropertiesStream(filter: PropertyFilter): Flow>> = flow {
        emit(Resource.Loading())
        
        // 1. Emit cached local listings for instant rendering
        val cached = localDao.getProperties(filter.city)
        if (cached.isNotEmpty()) emit(Resource.Success(cached.map { it.toDomain() }))

        try {
            // 2. Fetch fresh listings from Supabase cloud
            val remoteListings = supabaseApi.fetchProperties(filter.toQueryMap())
            localDao.insertAll(remoteListings.map { it.toEntity() })
            emit(Resource.Success(remoteListings.map { it.toDomain() }))
        } catch (e: Exception) {
            emit(Resource.Error(e.localizedMessage ?: "Failed to sync remote listings"))
        }
    }.flowOn(Dispatchers.IO)
}
