Project Overview & Objectives

Engineered an end-to-end donation and payment processing infrastructure integrating Tingg Checkout v3. Built a decoupled Node.js serverless microservice to abstract authentication, generate encrypted request payloads, trigger Mobile Money STK push PIN prompts, and ingest asynchronous transaction webhooks.

Key Engineering Accomplishments:

  • Engineered secure token exchange using OAuth2 Bearer Authentication without exposing API secrets to client browsers.
  • Implemented automated retry mechanisms and resilient error handling for timeout-prone telecom networks.
  • Built automated Postman sandbox collection for automated UAT test suites and regression validation.
  • Deployed production-ready environment configuration with zero leakages of merchant credentials.

Technology Stack:

Drupal Node.js (Serverless) Tingg Checkout v3 API OAuth2 REST APIs Postman Mobile Money (MTN / Airtel)

System Architecture

Decoupled 3-tier architecture: Drupal client frontend initiates transaction intents -> Serverless Node.js backend handles OAuth2 client credential token exchange with Tingg -> Tingg API triggers real-time STK push on user handset -> Webhook updates status in real-time.

// Node.js Tingg Checkout v3 Serverless Proxy
const axios = require('axios');

async function initiateTinggPayment(req, res) {
  try {
    const { amount, currency, phone, merchantRef } = req.body;
    
    // 1. OAuth2 Server-to-Server Token Exchange
    const tokenRes = await axios.post(process.env.TINGG_AUTH_URL, {
      client_id: process.env.TINGG_CLIENT_ID,
      client_secret: process.env.TINGG_CLIENT_SECRET,
      grant_type: 'client_credentials'
    });
    
    const accessToken = tokenRes.data.access_token;
    
    // 2. Initiate STK Push Payment Request
    const paymentRes = await axios.post(
      process.env.TINGG_CHECKOUT_URL,
      {
        merchantTransactionID: merchantRef,
        customerMSISDN: phone,
        amount: amount,
        currencyCode: currency,
        serviceCode: process.env.TINGG_SERVICE_CODE,
        callBackUrl: process.env.WEBHOOK_CALLBACK_URL
      },
      { headers: { Authorization: `Bearer ${accessToken}` } }
    );
    
    return res.status(200).json({ success: true, checkoutUrl: paymentRes.data.checkoutUrl });
  } catch (error) {
    return res.status(500).json({ success: false, message: error.message });
  }
}
